Specifications Met
  • Measures distances ≥ 5 cm and ≤ 50 cm from the sensor face
  • Displays distance in cm with leading zeros (e.g., 0005, 0050)
  • Displays "- - - -" (only segment g active per digit) for distances > 50 cm
  • Retinal persistence multiplexing — no visible flicker
  • 2 ms persistence delay per digit → 8 ms full refresh cycle (~125 Hz)
How Distance is Calculated
distance = (count × 10 × 343) / 20000
count = number of 10 µs loop iterations ECHO stays high
× 10 → converts to microseconds
× 343 → cm/s speed of sound (m/s → cm/µs scaled)
÷ 20000 → divide by 2 (round-trip) and unit conversion

The ECHO pin stays HIGH for a duration proportional to the round-trip time of the ultrasonic burst. Counting 10 µs increments and applying the formula above gives distance in centimeters.

Key Design Decisions
  • ECHO connected to PC0 (analog port) to avoid PD contention with UART TXD on PD1
  • Common-cathode display: digit enable pins are active-LOW (PORTB &= ~(1 << digit))
  • PORTD drives all 8 segment pins simultaneously with a single byte write
  • 30 ms timeout loops prevent infinite blocking if no echo is returned

Architecture & Source Code
01
Trigger
Pull TRIG low for 2 µs, then high for 10 µs, then low again to fire a 40 kHz burst.
02
Wait ECHO↑
Spin-wait on PINC until ECHO goes HIGH. Timeout after 30 ms to avoid blocking.

Count 10 µs increments while ECHO remains HIGH — this measures round-trip time.

main.c — ECE 231 Lab 8.3 
// Jiacheng Jason Li  ECE 231 Lab 8.3  5/2/2026

#include <avr/io.h>
#include <util/delay.h>

#define TRIG       PB0   // Arduino D8
#define ECHO       PC0   // Arduino A0
#define DIG1       PB4   // leftmost digit
#define DIG4       PB1   // rightmost digit
#define DIGIT_MASK ((1<<PB4)|(1<<PB3)|(1<<PB2)|(1<<PB1))
#define PERSISTENCE 2

unsigned char ledDigits[] = {
    0x3F, 0x06, 0x5B, 0x4F, 0x66,
    0x6D, 0x7D, 0x07, 0x7F, 0x67
};

// Disable all digit select lines (active LOW display)
void disable_digits(void) {
    PORTB |= DIGIT_MASK;
}

// Illuminate one digit for PERSISTENCE ms
void show_digit(unsigned char digit, unsigned char value) {
    disable_digits();
    PORTD = value;
    PORTB &= ~(1 << digit);
    _delay_ms(PERSISTENCE);
}

// Display a 4-digit number with leading zeros
void display_number(unsigned int num) {
    show_digit(DIG1, ledDigits[(num / 1000) % 10]);
    show_digit(DIG2, ledDigits[(num / 100)  % 10]);
    show_digit(DIG3, ledDigits[(num / 10)   % 10]);
    show_digit(DIG4, ledDigits[ num           % 10]);
}

// Show "----" when object is out of range (> 50 cm)
void display_dash(void) {
    unsigned char dash = 0x40;  // only segment g
    show_digit(DIG1, dash); show_digit(DIG2, dash);
    show_digit(DIG3, dash); show_digit(DIG4, dash);
}

// Measure round-trip time and convert to cm
unsigned int measure_distance_cm(void) {
    unsigned int count = 0, timeout = 0;

    // Send 10 µs trigger pulse
    PORTB &= ~(1 << TRIG);  _delay_us(2);
    PORTB |=  (1 << TRIG);  _delay_us(10);
    PORTB &= ~(1 << TRIG);

    // Wait for ECHO to go HIGH (with timeout)
    while (!(PINC & (1 << ECHO))) {
        if (++timeout > 3000) return 999;
        _delay_us(10);
    }

    // Count 10 µs increments while ECHO is HIGH
    while (PINC & (1 << ECHO)) {
        if (++count > 3000) break;
        _delay_us(10);
    }

    // distance (cm) = count × 10 µs × 343 cm/s ÷ 2
    return (unsigned int)((count * 10UL * 343UL) / 20000UL);
}

int main(void) {
    DDRD   = 0xFF;              // segment pins = output
    DDRB  |= (1 << TRIG) | DIGIT_MASK;
    DDRC  &= ~(1 << ECHO);      // ECHO = input
    PORTB &= ~(1 << TRIG);
    disable_digits();

    while (1) {
        unsigned int d = measure_distance_cm();
        int i;
        for (i = 0; i < 60; i++) {
            if (d > 50) display_dash();
            else        display_number(d);
        }
    }
}

Multiplexing Timing

The display refreshes all 4 digits in under 8 ms, well inside the 33 ms threshold for retinal persistence (30 Hz). Each measurement is displayed for ~60 full refresh cycles before re-sampling the sensor.

4 digits × 2 ms = 8 ms/frame → ~125 Hz refresh
Retinal persistence threshold: 33 ms (30 Hz)
Lessons Learned
  • ECHO placed on PC0 avoids UART TXD contention on PD1 (segment b wire)
  • Integer-only math (no floats) keeps code fast and avoids libm overhead on AVR
  • Separate timeout loops for ECHO rising and falling edges prevent infinite loops
  • Splitting display refresh into 60 loops keeps screen stable between sensor reads
